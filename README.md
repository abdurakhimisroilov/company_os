# COMPANY OS — Корпоративная Система Управления

## Обзор
Полнофункциональная корпоративная платформа для торговых компаний (~20 сотрудников).
Включает: ERP, CRM, управление складом, финансовый учёт, задачи, мессенджер.

## Технологии
- Мобильное приложение: Flutter (Android APK)
- Backend: NestJS + TypeScript
- База данных: PostgreSQL 15
- Файловое хранилище: MinIO (S3-совместимое)
- Реал-тайм: Socket.IO (WebSockets)
- Push уведомления: Firebase Cloud Messaging
- Кэш: Redis

## Быстрый старт

### 1. Требования
- Node.js >= 20
- Flutter >= 3.19
- Docker + Docker Compose
- Android Studio / JDK для сборки APK

### 2. Backend (Сервер)
```bash
cd backend
cp .env.example .env
# Заполните .env своими значениями
docker-compose up -d
npm install
npm run build
npm run seed  # Создать начальные данные (роли, super admin)
npm run start:prod
```

Backend доступен на: `http://localhost:3000`
Swagger документация: `http://localhost:3000/api/docs`

### 3. Мобильное приложение
```bash
cd mobile
flutter pub get
# В lib/core/constants/app_constants.dart укажите IP вашего сервера
flutter run  # Для разработки
```

### 4. Сборка APK для Android
```bash
cd mobile
# Создайте keystore (только один раз):
keytool -genkey -v -keystore android/app/release-key.jks -keyalg RSA -keysize 2048 -validity 10000 -alias company-os

# Заполните android/key.properties
# Запустите сборку:
build_apk.bat  # (Windows) или ./build_apk.sh (Linux/Mac)
```

APK будет в: `build/app/outputs/flutter-apk/app-release.apk`

### 5. Первый вход
После запуска сервера и выполнения seed:
- **Email:** `admin@company.com`
- **Пароль:** `Admin123!`
- **Роль:** `SUPER_ADMIN`

## Роли пользователей
| Роль | Описание |
|------|----------|
| `SUPER_ADMIN` | Полный доступ ко всем модулям, конфигурациям и управлению сотрудниками |
| `ADMIN` | Управление всеми бизнес-операциями, продажами, финансами и складом |
| `DEPARTMENT_MANAGER` | Управление своим отделом, утверждение задач и документов |
| `EMPLOYEE` | Доступ к персональным задачам, чатам, документам и базовым операциям |

## Модули
1. **Дашборд** — сводная финансовая статистика, графики доходов и расходов, ключевые KPI
2. **Финансы** — доходы, расходы, баланс счетов (касса, банк), учет задолженностей
3. **Приходы товаров** — учёт поступлений от поставщиков, накладные, распределение доп. расходов
4. **Склад** — каталог продуктов, остатки, учет партий, перемещения и инвентаризация
5. **Продажи** — оформление заказов покупателей, счета-фактуры, дебиторская задолженность
6. **Сделки** — CRM-модуль с Kanban-доской этапов воронки продаж
7. **Отчёты** — Отчет о прибылях и убытках (P&L), Cashflow, экспорт в PDF и Excel
8. **Задания** — постановка, делегирование и контроль выполнения задач со сроками
9. **Мессенджер** — корпоративный командный чат, каналы отделов и личные сообщения
10. **Сотрудники** — HR-модуль, профили сотрудников, должности и отделы
11. **Поставщики** — реестр поставщиков, условия оплаты, история поставок
12. **Клиенты** — CRM-база контрагентов, балансы взаиморасчетов
13. **Документы** — централизованное хранилище файлов, договоров и актов
14. **Настройки** — конфигурация компании, валюты, реквизиты, интеграции

## Резервное копирование
```bash
# Резервная копия базы данных PostgreSQL:
docker exec company_os_postgres pg_dump -U company_os_user company_os > backup_$(date +%Y%m%d).sql

# Восстановление из резервной копии:
docker exec -i company_os_postgres psql -U company_os_user company_os < backup_20240101.sql
```

## Безопасность
- Пароли пользователей защищены хэшированием с использованием bcrypt (соль 10 раундов)
- Аутентификация на основе JWT с механизмом ротации access и refresh токенов
- Строгая система ролевого доступа (RBAC Guards) на уровне NestJS контроллеров
- Полный аудит-лог (Audit Trail) всех финансовых и складских проводок
- Использование HTTPS / TLS и WSS для всех сетевых подключений в продакшн среде
